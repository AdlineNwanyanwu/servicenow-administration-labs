
# ServiceNow Administration Labs

## Overview
This repository documents my hands-on learning and technical development through the ServiceNow RiseUp program.

My focus is on ServiceNow platform administration, IT Service Management (ITSM), JavaScript scripting, workflow automation, and platform configuration.

## Technical Areas

### 1. Platform Administration
- Users, groups, and roles
- Access controls
- Lists and forms
- Application configuration
- Update sets

### 2. IT Service Management (ITSM)
- Incident management
- Knowledge management
- Service Catalog
- Request fulfillment

### 3. JavaScript and Scripting
- JavaScript fundamentals
- Client Scripts
- Business Rules
- Conditional logic and arrays

### 4. Workflow Automation
- Flow Designer
- Approvals and notifications
- Integration Hub fundamentals

### 5. Reporting and Troubleshooting
- Reports
- Platform debugging
- Testing and troubleshooting

## Learning Objectives
- Strengthen practical ServiceNow administration skills
- Document technical solutions and lessons learned
- Prepare for the ServiceNow Certified System Administrator (CSA) exam
- Build a professional technical portfolio

## Status
Ongoing — documentation and examples will be added as labs are reviewed and organized.
